Enhancement 1 and 3: Dashboard Application (Software Engineering & Databases)

This enhanced dashboard application demonstrates improvements in both software design and database performance. The original client-server dashboard was refactored to separate business logic from the user interface, implement secure credential management, and improve overall maintainability.

Additional database-focused enhancements include query optimization through projections, indexing of frequently accessed fields, and controlled data retrieval to improve performance and scalability.

Enhancement 2: Secure Banking Login Application (Algorithms & Data Structures)

This enhancement focuses on redesigning an insecure authentication system using structured algorithms and modern data handling techniques. The original implementation relied on unsafe input handling and lacked protections against brute-force attacks.

The updated system introduces validated input handling, password hashing, and a map-based structure to track login attempts per user. These improvements demonstrate the application of data structures and algorithmic logic to strengthen security, improve reliability, and enforce controlled authentication workflows.
