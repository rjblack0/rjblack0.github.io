## Professional Self-Assessment

Throughout my time in the Computer Science program, I developed a strong foundation in software engineering, algorithmic problem solving, database systems, and secure coding practices. Building this ePortfolio allowed me to not only strengthen those skills, but also demonstrate them through improved, real-world artifacts that reflect my growth as a developer.

One of my biggest areas of growth was learning how to design and evaluate computing solutions using appropriate data structures and system architecture. In my Secure Banking Login Application, I redesigned the authentication workflow by adding structured validation, hashed credential comparison, and per-user login tracking using map data structures. I later refactored the program into an object-oriented design, introducing classes such as AuthenticationSystem and CustomerRecord to reduce global state and improve maintainability. This process helped me better understand how to balance simplicity, scalability, and security in real applications.

My work on the Animal Shelter Dashboard further expanded my experience with full-stack systems and database-driven applications. I improved the structure of the application by separating concerns, implementing configuration management, and refining database interactions. By introducing query optimization techniques such as projections and indexing strategies, I improved both performance and scalability. This project reinforced how backend improvements can have a major impact on overall system efficiency.

Throughout the program, I also developed a strong security mindset. Across multiple artifacts, I identified and addressed issues such as plaintext password storage, lack of input validation, and unsafe data handling. By implementing validation controls, hashed authentication, and structured workflows, I demonstrated how security can be integrated into system design rather than added as an afterthought.

In addition to technical skills, I strengthened my ability to communicate and present my work clearly. Through the code review process and enhancement narratives, I practiced analyzing existing systems, explaining design decisions, and documenting improvements in a way that is accessible to both technical and non-technical audiences. This is an essential skill for working in collaborative environments and supporting decision-making.

The artifacts in this ePortfolio demonstrate my ability to work across software engineering, algorithms and data structures, and databases as connected disciplines. Rather than treating them separately, these projects show how they come together in practical applications, such as combining authentication logic, data structures, and security-focused design in the banking system, or integrating backend processing with user-facing components in the dashboard.
