## Professional Self-Assessment

Throughout my time in the Computer Science program, I have developed a strong foundation in software engineering, algorithmic problem solving, database systems, and secure coding practices. The process of completing my coursework and developing this ePortfolio has allowed me to not only build technical skills, but also to demonstrate them through tangible, improved artifacts that reflect my growth as a developer.

One of the most important areas of development has been my ability to design and evaluate computing solutions using appropriate data structures and system architecture. In my Secure Banking Login Application, I redesigned the authentication workflow by introducing structured validation, hashed credential comparison, and per-user login tracking using map data structures. I further improved this artifact by refactoring it into a more object-oriented design, introducing classes such as AuthenticationSystem and CustomerRecord to reduce global state and improve maintainability. This demonstrates my ability to apply both algorithmic reasoning and software design principles while managing trade-offs between simplicity, scalability, and security.

Next, my work on the Animal Shelter Dashboard further demonstrates my ability to design full-stack systems that integrate user interfaces with backend databases. In this project, I improved the structure of the application by separating concerns, implementing configuration management, and enhancing database interactions. I incorporated query optimization techniques such as projections and prepared indexing strategies to improve performance and scalability. This reflects my ability to work with real-world data systems and apply database best practices to improve efficiency and usability.
Throughout the program, I have also developed a strong security mindset. In multiple artifacts, I identified and addressed vulnerabilities such as plaintext password storage, lack of input validation, and unsafe data handling. By introducing validation controls, hashed credential comparisons, and structured authentication workflows, I demonstrated the ability to anticipate and mitigate potential security risks. At the same time, I developed an understanding of the difference between demonstration-level implementations and production-level systems, recognizing the importance of secure credential storage and system architecture in real-world applications.

As I was developing these technical skills, I also strengthened by ability to communicate professionally and to collaborate effectively. Through the code review process and enhancement narratives I practiced analyzing existing code, identifying areas for improvement, and clearly explaining design decisions and trade-offs. Writing structured documentation and aligning my work with defined course outcomes helped me gain the ability to communicate technical concepts to both technical and non-technical audiences. This is an essential skill for working in collaborative environments and supporting stakeholder decision-making.

The artifacts included in this ePortfolio collectively demonstrate my ability to work across the core areas of computer science: software design and engineering, algorithms and data structures, and databases. Rather than treating these areas as separate disciplines, this portfolio shows how they interact in practical applications. For example, the authentication system in my banking application combines algorithmic logic, appropriate data structures, and security-focused design, while the dashboard project integrates backend data processing with frontend user interaction and system-level design decisions.

Collectively, these artifacts demonstrate my achievement of the core computer science course outcomes, including my ability to collaborate and communicate technical concepts effectively, design and evaluate computing solutions using algorithmic principles, apply modern tools and techniques to develop efficient systems, and maintain a strong security mindset by identifying and mitigating potential vulnerabilities. These skills are supported through both my technical implementations and the accompanying documentation and analysis throughout this portfolio.
Overall, this ePortfolio represents my growth from writing functional code to designing structured, maintainable, and secure systems. It highlights my ability to evaluate existing implementations, apply appropriate tools and techniques, and improve systems in a way that aligns with industry practices. As I move forward in my career, I aim to continue building on these skills in backend development and secure software engineering, with a focus on designing scalable systems and integrating security into every stage of development.
